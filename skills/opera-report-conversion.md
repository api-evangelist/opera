# Report a conversion event to Opera Ads

Advertisers report post-click conversions (install, register, login, purchase,
place_bet, or custom) to Opera Ads so campaigns can optimize and attribute.

## Auth
- No bearer token: identification is via the `cvid` (conversion ID assigned by Opera)
  and the `click_id` (generated by Opera Ads, max 512 chars).

## Steps
1. Capture the `click_id` when a user arrives from an Opera Ads click.
2. On conversion, call `reportConversionEvent` — `POST https://cb.adx.opera.com/marketing/pb`
   with JSON body containing:
   - `cvid` (required) — your Opera conversion ID.
   - `click_id` (required) — the stored click identifier.
   - `event_name` (required) — one of install, register, login, purchase, place_bet, or a custom name.
   - optional `partner`, `event_value`.
3. Check the response: HTTP 200 with `status` 0 indicates the event was accepted.

## Rules
- May also be sent as GET/POST query-string; JSON body is preferred for structured events.
- Custom event names must be arranged with Opera Ads in advance.
