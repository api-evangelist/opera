# Opera Ads

> Opera Ads is the advertising and monetization platform of Opera, the web-browser company. It offers advertisers a self-serve Ad Manager and publishers an SDK/inventory platform, exposed through the Opera Ads Open API (advertiser Report, publisher Inventory Management, publisher OFP Report, ADX DSP Report, server-to-server Marketing/conversion, and a TUS-based File Upload API). This file is an API Evangelist companion to Opera's own llms.txt (opera-llms.txt), which covers the browser products rather than the API surface. Generated from Opera's public documentation at https://doc.adx.opera.com/.

## APIs

- [Opera Ads Open API docs](https://doc.adx.opera.com/): Advertiser and publisher REST APIs, bearer-token authenticated.
- [Report API](https://doc.adx.opera.com/advertiser/report-api): POST daily campaign reporting (impressions/clicks/conversions/spend) at https://ofa.adx.opera.com/oapi/v1/report/campaign_daily. Rate limit 100 req/min; date range max 90 days.
- [Inventory Management API](https://doc.adx.opera.com/publisher/inventory-management-api): App and placement CRUD at https://ofp.adx.opera.com/openapi/inventory/v1.
- [Publisher (OFP) Report API](https://doc.adx.opera.com/publisher/ofp/report): Measurement/dimension revenue reporting at https://ofp.adx.opera.com/openapi/report/v1/query.
- [SSP Report API](https://doc.adx.opera.com/adx/ssp/report): Legacy token-in-query inventory report at https://ofp.adx.opera.com/openapi/reports.
- [DSP Report API](https://doc.adx.opera.com/adx/dsp/report-api): Exchange performance at https://cms-adx.op-mobile.opera.com/oapi/report/dsp. Date range max 180 days.
- [Marketing (conversion events) API](https://doc.adx.opera.com/advertiser/events-integration/server-to-server-marketing-api): Server-to-server conversion postbacks at https://cb.adx.opera.com/marketing/pb.
- [File Upload API](https://doc.adx.opera.com/advertiser/file_upload_api): TUS 1.0.0 resumable uploads; API key or HMAC-SHA256; host issued per customer.
- [OpenRTB Integration Guide](https://doc.adx.opera.com/adx/openrtb/): Programmatic exchange (ADX) integration.
